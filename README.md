# Yiqing Skylar Yu Academic Website

This is a Quarto academic website for Yiqing Skylar Yu. The current version uses Dr. Gang He's Quarto Academic Website Template as the visual and structural base, with Skylar's existing research, teaching, mentoring, publication, and CV content migrated into that cleaner shell.

Routine edits are meant to happen in readable `.qmd` pages or simple `.yml` data files.

## Preview The Website

1. Install Quarto from <https://quarto.org/docs/get-started/>.
2. Open Terminal.
3. Go into this website folder:

```bash
cd "yiqingskylaryu.github.io"
```

4. Preview the site:

```bash
quarto preview
```

Quarto will print a local preview link. If you only want to rebuild the static files, run:

```bash
quarto render
```

The generated GitHub Pages-ready site appears in `docs/`.

## Edit Page Text

Most public page text is in these files:

- `index.qmd` for the homepage
- `research.qmd` for the research page
- `teaching.qmd` for the teaching portfolio
- `mentoring.qmd` for the mentoring page
- `publications.qmd` for the publication page introduction and section headings
- `cv.qmd` for the CV page and living CV link

Open the file, edit the regular text, save, and preview again.

## Update Publications

Edit only this file for publication data:

- `data/publications.yml`

Each publication entry has a section, year, authors, title, journal, volume or page details, DOI or URL, and note. Copy an existing entry, paste it in the right section, and edit the fields.

Do not invent DOI links. Leave `doi_or_url` blank if there is no public link yet.

## Add A Teaching Material

Teaching material records live here:

- `data/teaching-materials.yml`

If you add a public file, put it in `files/teaching-materials/` and use a path like:

```yaml
file_or_url: "files/teaching-materials/psy250-public-syllabus.pdf"
```

Before adding syllabi or assignments, remove private notes, student information, internal course-management details, and copyrighted material that should not be public.

## Update Research Or Course Data

The public pages currently use hand-written prose, but these data files preserve simple source information for future maintenance:

- `data/research-projects.yml`
- `data/courses.yml`
- `data/teaching-materials.yml`

Update the data file first when a project, course, or material changes, then update the matching public page text if needed.

## Replace The Headshot

Replace this file with a new professional headshot:

- `images/headshot.jpg`

Keep the same filename unless you also update the image path in `index.qmd`.

## Change Links Or Navigation

Edit `_quarto.yml` to change:

- site title
- navbar items
- Google Scholar link in the navbar/footer
- email link in the navbar
- output folder

The current CV link also appears in `cv.qmd`.

## Change Color Or Font Settings

Edit `styles.css`.

The safest first changes are near the top:

```css
:root {
  --skylar-ink: #243230;
  --skylar-muted: #66726f;
  --skylar-line: #e4e8e6;
  --skylar-accent: #2f6f68;
  --skylar-accent-dark: #1d514c;
  --skylar-bg: #fbfbfa;
}
```

Avoid changing files inside `docs/`; that folder is generated by Quarto and can be recreated.

## Deploy With GitHub Pages

This project renders to `docs/`, which GitHub Pages can serve directly.

When you are still editing, keep the GitHub repository private and leave GitHub Pages turned off.

When you are ready to publish:

1. Push this folder to GitHub.
2. In the repository settings, set GitHub Pages to serve from the `docs/` folder on the `main` branch.
3. Run `quarto render` before committing updates.
